## Run Locally

Clone the repository:

```bash
git clone https://github.com/AyushSingh-coder-web/ayush-portfolio-2026.git
```

Navigate into the project:

```bash
cd ayush-portfolio-2026
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
